# ITパスポート学習室 v0.2

iPhone向けPWA試作版。オリジナル例題9問（公式過去問ではありません）、4択採点、固定解説、分野別正答率、誤答復習、localStorage保存、JSONバックアップに対応。

## 公開方法
1. フォルダ内の4ファイルをGitHubリポジトリのルートにアップロード。
2. Settings > Pages で Deploy from a branch を選択し、main / root を公開。
3. 公開された HTTPS URL を iPhone Safari で開く。
4. Safariの共有メニューから「ホーム画面に追加」を選択。

## 注意
- 端末のブラウザ保存データを消すと学習履歴も消える可能性があります。定期的に成績分析画面からJSONをエクスポートしてください。
- AI接続、IPA公式問題の取り込み、クラウド同期、ログインは未実装です。
- 正式運用では問題の出典・年度・正答例・図表を照合し、AI解説はサーバー側API経由で実装します。APIキーをブラウザに埋め込まないでください。
- ファイルを直接開くよりHTTPSホスティングを推奨します。Service WorkerはHTTPS等の安全なコンテキストが必要です。
